# maya chen portfolio website

hey there, welcome to the portfolio project for maya chen, built this as a high-end showcase for a senior full-stack and distributed ai systems architect, honestly so hyped with how this turned out

### what this actually is

basically wanted to build something that feels super premium, not your usual boring dev portfolio, started with this pure black gateway modal that hits you right when you load in with a pulsing mc monogram logo and gives you two simple choices, enter with sound or enter muted, once you click enter with sound you get this rich ambient soundtrack that starts playing alongside delicate synthesized chimes whenever you hover or click on stuff, all generated in real time using the browser web audio api without needing heavy external sound effect downloads

### the vibe and aesthetic

went all in on a maximalist high-contrast monochrome look, lots of frosted glass everywhere, backdrop blur filters, silver borders, and subtle shadows, paired playfair display for the bold editorial headlines with space grotesk for the clean technical body type, plus real crisp photography that never gets dimmed or greyed out by annoying overlays, also threw in a dynamic particle canvas drifting in the background that has pointer events disabled so it never gets in the way of your clicks

### what is inside

- gateway entrance modal with that pulsing logo and sound toggle
- sticky frosted glass navigation bar with a live animated equalizer wave
- hero section with oversized typography and a floating photo card that drifts gently
- live stat counters that roll up when you scroll down to them
- skills matrix laid out cleanly without generic badge clutter
- interactive career timeline highlighting distributed systems and ai milestones
- four featured engineering case studies with rich modal popups for deep dives
- working contact dispatch form with instant feedback and chime confirmation
- editorial footer with simulation disclaimer and back to top button

### tech stack

kept this totally lightweight and blisteringly fast, pure html5, modern css with custom variables, and vanilla javascript modules, no heavy framework runtime needed for this, font awesome 6 for icons, and google fonts for typography

### how to run it locally

clone or open up this directory, fire up any static server or run the development server with:

```bash
npm run dev
```

then just pop open your browser at port 3000, hit enter with sound, and enjoy the vibe
